# 宏观-中观-微观三层联动分析

一套把「政策/事件」映射到「板块」再到「标的与操作」的分析框架，用于识别预期差与结构性机会。

## 为什么需要它

单一维度分析容易得出「普涨/普跌」这类无效结论。三层联动要求每一层都完成传导验证：

```
宏观驱动（政策、地缘、流动性）
      ↓ 传导路径
中观传导（板块分化、拥挤度）
      ↓ 预期差
微观验证（时间维度、验证节点、风险）
```

## 三层内容

- **宏观**：地缘政治博弈、货币政策框架与统计口径、流动性成因与定价状态
- **中观**：强势/弱势板块分类、拥挤度三条件（估值透支 + 高杠杆 + 流动性收紧）
- **微观**：市场预期 vs 行业预期的预期差、短/中/长期策略、验证清单与风险应对

## 使用方式

将根目录 `SKILL.md` 作为技能指令加载，或在 AGENTS.md 中引用：

```markdown
## 分析技能
- **macro-micro-linkage-analysis**: 宏观-中观-微观三层联动分析
```

分析时按「宏观驱动识别 → 中观传导验证 → 微观操作建议 → 验证清单」四段输出。

## 边界

框架提供的是分析结构与检查清单，不构成投资建议；结论需要外部数据源与人工复核。
